# V1 S1e Process-Wording Change Log

Date: 2026-10-14

## Purpose

Preserve the previously frozen S1d packets as historical artifacts and create a new pre-distribution wording version based on the researcher's revised CODER_1 workbook.

## Substantive wording change

The construct label used in coder-facing material is changed from:

- 企業決策介面

to:

- 企業決策過程

The intended judgment remains whether a given AI-function × decision-function pairing implies a distinct organizational choice, setting, or judgment. No G mapping, mechanism definitions, item identities, or per-coder random order are changed.

## Layout change inherited from researcher-edited CODER_1

In the coder answer sheet, the common 文獻樣態說明 column is placed at the far right (column L), and Q1–Q5 occupy columns G–K. This layout is replicated in CODER_1, CODER_2, and CODER_3.

## Cleanup of accidental global replacement

The researcher's edited CODER_1 globally replaced the word 介面, which also changed technical examples such as 使用者介面 and 系統串接介面. The new packets preserve the intended construct wording 企業決策過程 while restoring technical terms in the explanatory sentence:

> 這裡的『企業決策過程』是研究上的名稱，不是指軟體畫面、使用者介面、API、系統串接介面或其他技術介面。
