網絡與測量 · 圖解 02｜概念容易混淆

二值化 Binary 與二模 Bipartite，根本不是同一個維度

「二值化」是把 W=0、1、2、20 轉成有邊或沒邊；「二模」是限制某種節點只能連另一種節點。Graph F 就是二模網絡，既可以保留 W 加權，也可以用 W≥1、2、3、5 進行二值化敏感度分析。Graph K 是功能單模投影，可同時做加權與二值對照。

公式與計算規則
Aij(t)=1[Wij≥t]
t ∈ {1,2,3,5}

對 F 的配對，W=3 在門檻 t=1、2、3 都是「有邊」，但 t=5 變成「無邊」。這是研究者改變操作門檻，不是歷史上真的失去聯繫。

可以解釋

能精確區分二值化門檻與二模網絡的構造限制。

不能直接推論

「一變成 0 就是發現真正的 Burt 洞」；或把四個門檻當成四批獨立資料。

來源：H1–H3 四門檻稽核（需權限）。

網絡與測量 · 圖解 03｜有效規模 vs 限制度

Effective Size 越高，不保證 Constraint 一定越低

想像 B 是班長：認識很多互不認識的同學，可能有較高有效規模；但 B 把大部分時間和資源放在少數強關係上，或朋友彼此還有替代路徑，限制度就未必低。兩個數字互補，而不是同一個指標算兩次。

公式與計算規則
ESi=ki−2ti/ki
Ci=Σj(pij+Σqpiqpqj)²

ES 公式是無向、無權簡化式；本研究 Graph K 的正式檢定是加權 ES／Constraint，不能拿簡化式替換結果。p 是相對連帶權重；Constraint 還會考慮直接權重集中與間接冗餘。

可以解釋

高 ES 可以提供「非冗餘聯繫較多」的次要訊號；低 Constraint 才對「低網絡約束」提供更直接的訊號。

不能直接推論

只因 ES 顯著就把某家族宣稱成唯一、不可替代的仲介；或未控制連線數就跨網絡比較 Constraint 絕對值。

來源：Burt 加權結果與方法來源（需權限）。

第三章補充｜為何不能把一般 Burt 直接貼到 F 上

在純二模圖中，普通 Burt 公式可能只反映「一個節點有多少條邊」

純二模、無向、無權、普通單模 Burt 公式

ESi=ki
Ci=1/ki

因為一個 AI 節點的鄰居都是決策節點，而那些決策節點間沒有同類邊。普通公式中的鄰居彼此冗餘項會消失；在加權形式下 Ci=Σjpij²。

本研究做的是專門的二模檢查

H1：缺直接邊
H2：替代路徑偏少
H3：端點非冗餘

WP1 使用二模特化的 H1–H3 判準及指標，而非把上述簡化式直接當結論。本次二模 ES 在 W≥1／2／3 出現常數 1 退化；W≥5 才能檢定。

為什麼教授需要知道這點？ 因為網絡太稠密、指標對該種資料退化時，「沒有顯著」有時反映辨別能力不足，不表示世界上不存在仲介。

第五章｜若教授想問「大型學術引用網絡呢？」

目前沒有把 783 篇文獻做成「論文引用論文」的正式結構洞網絡

有論文 PDF、作者、年份、DOI 或參考文獻書目，不代表已經有可運算的引用關係。真正的論文引用圖需要：每篇文獻的唯一 ID、它引用了哪些論文的 ID、引用方向、文獻範圍、資料缺漏比例及年代，還要重新選擇適用的零模型。

文獻與 DOI 身分核對→擷取「來源論文 → 被引論文」→去重、補年份與覆蓋率→文獻引用網絡＋Burt／零模型

這是可能新增的獨立研究軌道，尚未執行，也不包含在現有 Graph F／K 或專利 C1/C2 已驗收結果內。沒有必要為了湊成三種大型引用圖，就把文獻共現邊改名叫引用邊。

CPC 版正式結果 已核對 GitHub B 提交，相關原始研究協定仍在私人庫並保留凍結紀錄。

適合直接對教授講的版本

「老師，我們文獻端實際做了兩張功能網絡：F 是 AI×Decision 明示配對，K 是 22 類功能的同篇共現。它們都不是論文引用圖。我們用二模 H1–H3 和單模加權 Burt 指標分別檢驗，發現相對低整合成立，卻沒有共同支持關鍵結構洞。大型引用網絡是另外用專利和公司資料跑的 C，結果是在既定零模型下未偵測到超額跨群仲介。CPC B 正在補上。這三種觀察單位不同，不能合成『三次證明沒有洞』。」
