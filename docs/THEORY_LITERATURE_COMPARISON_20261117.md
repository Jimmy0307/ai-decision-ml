# AI × Decision｜結構洞與研究缺口：理論文獻、差異、公式及本研究對照

> 2026-11-17／2026-11-18 指導教授報告使用。**學術理論核對版，不是 12 篇全部已完成實證重跑。** 文獻年份為發表年，DOI 可點回原始出版來源；公式均標示是否精確／條件化／教學示意。

## 一、我們到底在爭論什麼？

### 三個不能互相取代的研究命題

**功能不足整合（functional under-integration）**：10×12 功能矩陣中某配對相對於條件化 null expectation 明顯較少；V9 frozen 結果 16 depleted，**104/120 配對有已觀測邊**，不等於全部缺邊。

**路徑與群體橋接（path or group brokerage）**：引用網路、合作者網路中誰位於資訊傳遞路徑上？依 Freeman 或 Gould–Fernandez 的方法測量；可能存在替代路徑。

**Burt 結構洞（nonredundant ego contacts）**：在明確的關係網路，某節點的鄰居是否互相缺乏連結，提供非冗餘關係？不要求刪除該節點使全圖斷線，因此「存在替代路徑」不是否定 Burt 的充分條件。

**Limitation 未解問題**：作者自己寫的限制是否被後續研究實質處理？這需要原文摘錄、DOI 追蹤和反證審核，**不是** Burt 的另一種計分方式。

## 三、重點公式與辨識界線

### E1｜AI × Decision 的不足呈現（不是 Burt）

```text
R_ab = O_ab / E_null[O_ab]；並對 empirical p-values 施行 BH–FDR
```

O_ab = 去重後某 AI×Decision 配對觀察次數；E_null = 保留約束條件的零模型期望。R<1 表示相對不足，但並非「完全沒有邊」，更非獨占仲介。

**對應研究狀態：**V5／V9 基準已執行；編碼品質需重新分析

### E2｜Burt network constraint

```text
C_i = Σ_{j∈N(i)} (p_ij + Σ_{q∈N(i), q≠i,j} p_iq·p_qj)²
p_ij = (z_ij + z_ji) / Σ_{k∈N(i)} (z_ik + z_ki)
```

p_ij：i 對 j 的雙向合計關係投入（z_ij+z_ji）占 i 全部關係投入的比例；p_qj 以 q 自身的關係總量正規化；j 取 i 的直接接觸者。直接依賴與經由共同接觸者的間接冗餘均計入。〔2026-11-18 更正：原說明未寫明雙向權重與 p_qj 的分母。Burt 1992 原書是否另乘 O_j 本次未能逐頁核對（UNVERIFIED_SOURCE_TEXT）；igraph／networkx 實作不含 O_j。〕

**對應研究狀態：**V11.1 作者網路已探索；原始跑批待回收

### E3｜Effective size / Efficiency

```text
ES_i = k_i − 2t_i/k_i；Efficiency_i = ES_i/k_i
```

適用於無向、無權簡單 ego 網路；k_i 是鄰居數，t_i 是鄰居彼此間的邊數；權重/方向網路不可直接套用。此式為 Borgatti（1997）對無向無權二元 ego 網路的簡化；Burt 一般式為 ES_i = Σ_j [1 − Σ_{q≠i,j} p_iq·m_jq]。

**對應研究狀態：**作者網路探索的理論對照

### E4｜Betweenness centrality

```text
B(v) = Σ_{s<t; s,t≠v} σ_st(v) / σ_st   （無向圖、無序配對；有向圖改對有序配對求和）
B'(v) = B(v) / [(n−1)(n−2)/2]   （無向圖標準化）
```

σ_st 為 s 與 t 之間的最短路徑數，σ_st(v) 為其中經過 v 的數量；〔2026-11-18 更正：原式「s≠v≠t」未排除 s=t，也未指明無序配對與標準化；以有序配對加總會使無向圖分數加倍。Freeman 1977 原文本次未取得，依標準教科書形式更正〕可辨識最短路徑控制，但不是 Burt nonredundancy 的必要條件。

**對應研究狀態：**Citation／coauthor 探索指標

### E5｜Gould–Fernandez roles（概念計數）

```text
GF_r(v) = Σ_{s≠t; s,t≠v} 1[(s→v) ∧ (v→t) ∧ ¬(s→t)] × I_r(g_s,g_v,g_t)
```

必須是開放二步路徑（s 未直接連 t）。角色：coordinator g_s=g_v=g_t；itinerant（亦稱 consultant／cosmopolitan）g_s=g_t≠g_v；gatekeeper g_s≠g_v=g_t；representative g_s=g_v≠g_t；liaison 三者互異。原 GF 為無權計數（另以隨機分組下的期望值比較）；加權正規化版本見 Zádor et al.（2022）。〔2026-11-18 更正：原式漏列 ¬(s→t) 與相異條件；「非原論文加權精確式」有誤導——原論文本為無權計數。〕

**對應研究狀態：**理論對照；尚未確認正式跑過 GF roles

### E6｜嚴格二分圖的特殊條件

```text
二分圖中 i 的鄰居 q, j 同屬另一側且彼此不相連：p_qj=0 ⇒ C_i=Σ_{j∈N(i)} p_ij²；若 i 的各邊等權 ⇒ C_i=1/k_i
```

是當前 simple bipartite 設定下的代數結論；不能外推為任一真實合作者網路都沒有結構洞。

**對應研究狀態：**Gap Validity V1 已驗證此限定情況

### E7｜骨架敏感度（本研究）

```text
Cross-component count = 10（robust16）/ 14（main q≤.01）/ 0（main q≤.05）
```

三種計數對應三種 backbone 定義，不能將 10 或 14 當成穩定的 Burt 洞數。

**對應研究狀態：**Gap Validity V1 直接重現

### E8｜Limitation → Future research 的驗證框架（尚非統計結論）

```text
Claim → paper DOI/page/quote → later work → resolution evidence → human adjudication
```

已解決、部分解決、重複提出、證據不足需以原文和後續文獻實證核定。詞彙命中不等於 gap。

**對應研究狀態：**目前僅 Limitation Scout V0.1 初篩

## 五、2026/11/18 教授會議的結論應如何限定？

- **可以說**：多層 network 的負面驗證具有資訊價值；二分功能低整合不等於 Burt；constraint 不能只依大小解釋；V9 人審編碼問題讓全量重掃必要。
- **不可說**：學界沒有結構洞；16 depleted 就是 16 個 Burt holes；本研究首次提出 two-mode brokerage；本研究已證明 constraint 失效；Limitation 有 100 篇未被解決。
- **下一步**：取回本機 V11.1 original logs + V5 全文；重跑 family coding 的全量可靠性；固定最後 Burt gate；平行做 Limitation 原文追蹤與後續文獻驗證。若仍不可識別，改採有真實交互作用／時間資訊的關係資料。
