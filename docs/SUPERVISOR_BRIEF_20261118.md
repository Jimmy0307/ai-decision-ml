我們已把 V5–V11.1 的研究鏈完整建檔，區分功能二分網路、引用網路、高階網路及研究者共同作者網路。已上傳的五個 ZIP 合計 1,030 個檔案成員，逐一驗證可讀並建立雜湊；整理 90 項量化指標、20 項方法、13 個版本條目與 V11.1 四位主要候選的裁決資訊。但 V11.1 原始合作資料仍在本機，不列為本次獨立重現成果。

## 最需要報告的數據

- **功能語料基準**：2,118 起始文獻，歷史 1,729 可解析全文；6,499 嚴格分析紀錄、3,125 雙端分類、783 篇可配對文獻與 2,180 文獻層級功能配對。
- **功能矩陣**：10×12＝120 格；104 格有觀測連結；47 格主檢定顯著，32 格通過四重穩健性檢查，其中 16 強整合、16 低整合。
- **Social Network**：V6–V9.1 引用網路、V10–V10.1 高階／超圖、V11–V11.1 作者合作加外部 OpenAlex 查核。至 V11.1 仍 **0 位 confirmed AI×Decision Burt broker**。
- **V11.1 原始執行摘要**：V9 查核 7,880 篇，7,835 篇有作者；獨立 26,443 位、合併 30,140 位作者；95 次匿名 API 呼叫；四候選中三否決、一資料不足。
- **敏感度與外部反證**：16/16 功能低整合配對具有替代路徑；骨架變更下跨分量為 10／14／0。外部合作使部分原候選缺乏獨占性。
- **重新掃描原因**：20 筆雙人編碼 AI 與 Decision family 僅 4/20 一致，Cohen κ=0.048／0.140；50 筆局部校正後 24/120 格改變且核心成員一進一出。原官方裁決 `FULL_REANALYSIS_REQUIRED`。
- **Limitation 線**：25,112 已選段落／1,104 文件 ID，100 文件有線索、142 片段命中，但後續文獻解決情形**尚未驗證**。
