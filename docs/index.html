為什麼重新掃描，而不是研究停滯？

既有凍結功能矩陣辨識 32 組穩健配對（16 過度、16 不足），但人工編碼品質檢查已使其中部分配對成員變動；而引用、三元、作者合作與外部替代合作檢查均未確認 Burt 仲介。若在編碼與來源資料尚未補齊時繼續調整結構洞門檻，結果不可稽核。因此目前進行的是 資料回收 → 全量人審校準／重新編碼 → 固定規則 → 最後一次 Burt 適配性檢查。若仍無法識別，改採有明確群體、時間和真實關係的資料，不把負結果包裝為不存在研究缺口。
