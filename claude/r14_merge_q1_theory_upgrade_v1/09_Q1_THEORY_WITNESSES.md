## What a witness is

**Every item below is a computational witness, i.e. a constructive example on a hand-built algebraic instance. It is not a proof of any general theorem.**

A witness can do two things:
* show that something exists (for example, Prop D6: a build region that is not an interval);
* refute a universal claim (for example, "misalignment ⇒ DL > 0" is refuted by W2).

Where the pack contains a proof, it is in Q/01–08, not in the code. The witness only reproduces the instance used in that proof. All numbers are SIMULATED_ONLY:
* no enterprise parameters;
* no human coder data;
* no ROI;
* no claim of V7 or empirical validity.

**Assembly and id resolution.**
* T1 (`w_dl_gov.py`) and T2 (`w_mono_rob_miss.py`) both used id "W5". The integrator assigns namespaced ids:
  * T2's δ witness is canonical **W5**;
  * T1's AL3 witness becomes **W_DL_AL3**;
  * T4's two witnesses become **W_MECH_ABL** and **W_IA_NDV**.
* The record that gets hashed contains:
  * the namespaced `id`;
  * `part` and `part_id`, which give the original source;
  * `set` (CANONICAL or SUPPLEMENTARY);
  * `status` (SIMULATED_ONLY).
* The hash is the SHA-256 of a canonical JSON with these properties:
  * dict keys are sorted, and non-string keys are converted to canonical JSON text;
  * set elements are sorted;
  * a Fraction becomes the string `"p/q"`;
  * separators are `(',', ':')` and the encoding is ASCII;
  * callables and non-finite floats are rejected.
* Only W5_WIDE draws random numbers, from a private `random.Random(20261015 + stream)` instance (fixed seed; the module-level random state is not used). All other witnesses are exhaustive over fixed grids. The declared module-level seed is 20261014.
* Witness engines use absolute `1e-9` ties; 51 uses a relative tie rule (51 l.673). On the integer/decimal data used here this makes no difference (Q/11 §2.13 item 4).

**Things that are part of a parent witness, not separate witnesses.**

* T2's "W7b" (Model C aligned) and "W7c" (Model C misaligned), named in Q/06, are parts (b) and (c) of **W7**.
* W8a part 2 and W8b parts (ii) and (iii) are inside W8a and W8b.

**Note on W5's margins (T7 per Q/11 A6).** Canonical W5 is kept unchanged because it must reproduce T-SEN-8's grid `1,1,1,1,0,0,0,1` exactly. Its margins are thin: `D(0) = 1`, `D(3) = −1` and `D(≥5) = 1` TWD, against `F_c = 24` and `N_1 v_1 = 30`. In W5_WIDE's deterministic check, W5 keeps a non-interval region in 398/400 draws at ±1 % joint perturbation, but only 162/400 at ±5 %.

W5 also depends on **two exact zeros**:
* the reused cost of U2's AI configuration is floored at exactly 0;
* U2's AI configuration has exactly zero ENG footprint.

With an ENG footprint of `1e−6`, or a cost floor of `0.01`, the region becomes an interval.

The supplementary witness W5_WIDE widens the numeric margins to 3, but it depends on the same two zeros. Use W5 only as an existence witness (Prop D6), and state the every-resource footprint condition with it (Q/04 §6).
