# S1D — 認知可讀性修補決定

**日期：** 2026-10-14。**決定者：** 研究者（核准 S1d），經 coordinator 轉達。

## 1. 發生了什麼

- 研究者在發送前對 S1c 編碼工具做了**非正式的可讀性檢查**（研究者本人閱讀，不是對編碼者施測）。
- 發現的理解風險：Q1 可能被讀成「我的公司是否需要／是否採用這類 AI」，而不是「這個功能配對本身是否形成一項可辨識的組織決策問題」。相關風險：「介面」被讀成軟體介面或 API；「企業決策」被窄化為高階策略決策；「這個組合特有」被讀成「只能出現在這個組合」；Q2 的「如果有」與「每題必填」看似衝突；Q1「無法確定」與 Q2「無法明確判定」不易區分。

## 2. 沒有發生什麼

- 沒有蒐集任何正式的編碼者資料。
- 沒有發送任何 S1c 檔案（NO_HUMAN_DATA_COLLECTED_UNDER_S1C=YES）。
- 沒有觀察到任何作答結果，也沒有任何結果影響本修補。
- 沒有改動任何題目的答案、類別歸屬、研究者答案鍵或題目 ↔ G 對照（後兩者仍密封、未開啟）。
- **這不是正式前測（NOT a formal pilot）**，不得在論文中描述為前測或預試。

## 3. 修補依據與範圍

修補完全基於理解風險，只增加澄清文字（`S1D_PROTOCOL.md` §2、`S1D_PATCH_DIFF.md`）；構念、類別意義、一致性規則、分析計畫都不變。每一種誤讀都有對應的阻擋文字與儲存格位址（`S1D_COGNITIVE_CLARITY_AUDIT.md`）。
