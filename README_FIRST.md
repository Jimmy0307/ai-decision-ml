## 不要再做的事

- 不再把某個單一部門、流程或 application 當整篇研究的研究本體。
- 不再由單一 use case 推企業導入結論。
- 不把舊 v1.0 的 `FINAL LOCAL VERDICT: PASS` 當成 v2.0 empirical/model validation。
- 不把 ordinal 0–3 等級當基數效用。
- 不把 missing input 補 0。
- 不把外部 productivity effect 直接當成本企業效果。
